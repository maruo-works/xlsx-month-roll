# xlsx-month-roll

毎月の定型 Excel（請求書の発行資料など）を「前月分をコピーして、月の表記と日付を直す」作業を、
**書式を崩さずに**まとめて行うコマンドです。

```bash
python -m xlsxroll 2026-09.xlsx 2026-10.xlsx --replace "9月=10月" --shift-months 1 --check "9月"
```

```

変更  請求書発行資料!B3: 2026-10-05 → 2026-11-05
変更  請求書発行資料!B4: 2026-10-31 → 2026-11-30
保存しました: 2026-10.xlsx  変更 3件 / 要確認 0件
```

## なぜ作ったか

Python で Excel を書き換えるとき、よく使われるライブラリ（openpyxl など）は**ファイルを読み込んで作り直す**ため、
既定のフォント・列幅・印刷設定・条件付き書式などが変わってしまうことがあります。
毎月くり返すファイルでは、こうした小さな崩れが積み重なります。

このツールは xlsx（中身は XML の zip）を作り直さず、**変える文字と数字の部分だけ**を置き換えます。
それ以外のファイルは1バイトも変えずにコピーします（テストで確かめています）。

## できること

- **文字の置き換え**：`--replace "前=後"` を何回でも指定でき、上から順に適用します。共有文字列・セルに直接入った文字の両方が対象です
- **日付を進める**：`--shift-months 1` で、日付の表示形式のセルだけを1か月進めます
  - 月末は月末のまま（9/30 → 10/31、1/31 → 2/28）
  - 組み込みの日付形式（日本語版 Excel の 55〜58 など）と、`yyyy"年"m"月"d"日"` のような独自の形式の両方を見分けます
  - 金額などの数字や、式の入ったセルは変えません
- **直し忘れの確認**：`--check "9月"` で、保存後に「9月」が残っているセルを知らせます（残っていると終了コード 1）
- **確認だけ**：`--dry-run` で保存せず、変わるところを一覧にします
- **元のファイルは残す**：元のファイルと同じ名前には保存できません
- **ふりがなは触らない**：日本語の文字に付いたふりがな情報（rPh）は書き換えません

## 試してみる

外部ライブラリは不要です（Python 3.11 以上）。

```bash
git clone https://github.com/maruo-works/xlsx-month-roll
cd xlsx-month-roll
python examples/make_sample.py examples/sample_2026-09.xlsx      # 架空の見本ファイルを作る
python -m xlsxroll examples/sample_2026-09.xlsx examples/sample_2026-10.xlsx \
  --replace "2026/09/01-2026/09/30=2026/10/01-2026/10/31" --replace "9月=10月" \
  --shift-months 1 --check "9月"
python -m unittest                                               # テスト
```

## できないこと（今の版）

- 1つのセルの中で、太字などで文字の途中の書式が分かれている場合、その境目をまたぐ置き換え
- 式の結果（例：`=EDATE(A1,1)`）の再計算。式はそのまま残すので、Excel で開いたときに再計算されます
- .xls（古い形式）・.xlsm（マクロ付き）
